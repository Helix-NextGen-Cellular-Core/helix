# Helix: A Flexible and Scalable NextGen Cellular Core

Helix is a scalable, cloud-native 5G core designed to improve control-plane performance while preserving the flexibility of the 3GPP Service-Based Architecture (SBA).

Helix enables independent scaling of network functions through UE-aware load balancing, distributed state management, and efficient per-UE state caching. It also supports fault recovery while maintaining per-UE consistency.

This repository hosts the source code and research artifacts for **Helix**, accepted at **ACM SoCC 2026**.
